1. PROJECT INITIALIZATION & FOUNDATIONAL ARCHITECTURE
--------------------------------------------------------------------------------
* Initial commit and repository setup (Commit: 5bdb936)
* Backend:
  - Built with FastAPI, SQLite, and SQLAlchemy ORM.
  - Multi-tier role management: Student, Teacher, Administrator, Developer.
  - Token-based JWT authentication with bcrypt/sha256 password hashing.
  - Database schema: Users, Complaints, TeacherRatings, AuditLogs.
* Frontend:
  - Zero-build vanilla JavaScript single-page application (SPA) with ES Modules.
  - Dynamic client-side hash router with role-based route protection.
  - Modular CSS design system (tokens, components, typography, dark/light theme).
* Core Complaint Lifecycle:
  - Anonymous student submissions (per-complaint random ANON-XXXX IDs).
  - Teacher verification queue (with self-verification prevention).
  - Public voting engine with weighted scoring:
    Score = (student_up - student_down) + 10 * (teacher_up - teacher_down).
